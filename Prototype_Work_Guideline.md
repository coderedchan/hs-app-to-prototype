# Figma Make prototype checklist

## 1. Plan

- [ ] Open the mission in [Handshake Learn](https://app.joinhandshake.com/learn) and confirm you have access to Figma Make through a Pro or Education plan.
- [ ] Select **Talk**. Pick one user, one task they need to complete and the screens they’ll use.

## 2. Build

- [ ] Open **Build**, read the project brief and use Figma Make to generate your first draft.
- [ ] Edit the screens to fit your idea. Make each main button open the right screen or confirm the action.
- [ ] In preview, complete the task from the first screen to the final result. Fix any buttons or screens that block progress.

Replace the brackets and paste this into Figma Make.

> Build a mobile prototype for [user] to [complete a task]. Create these screens in order: [screens]. Connect the main buttons and show [final result] when the task is complete.

## 3. Publish and submit

- [ ] Publish the prototype and copy the link.
- [ ] Open the link on a phone in a private browser window and complete the main task without signing in.
- [ ] Submit the link through **Share** in Handshake and confirm the submission went through.

If you’re entering the challenge, verify the deadline on the mission page. The brief listed November 30 at 11:59 p.m. PT.
