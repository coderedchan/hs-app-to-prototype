# Figma Make plan

The checklist in `Prototype_Work_Guideline.md` asks for one user, one task and the screens in order. This is that plan for CareerPilot.

| | |
|---|---|
| **User** | Maya, a recent interaction design graduate looking for her first product design job |
| **Task** | Find her best-matching job and apply to it with an AI-tailored resume |
| **Screens** | Home → Jobs → Job details → Review application → Application sent → Tracker |
| **Final result** | An "Application sent" confirmation, and the job appears in the Applied stage of her tracker |

The ready-to-paste prompts and the screenshots to attach are in [`submission/`](../submission/README.md).
