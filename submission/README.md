# CareerPilot submission kit

Everything you need to build the prototype in Figma Make and submit it through Handshake.

The form asks for **your published figma.site link**, a preview image and a short description. This folder gets you to that link quickly and holds the text to submit with it.

## What's inside

| Folder or file | Use it for |
|----------------|-----------|
| `1-prompts/` | Four prompts to paste into Figma Make, in order |
| `2-screenshots/` | Eleven phone screenshots to attach to the prompts as the visual target |
| `3-form-answers.md` | Answers for each field of the Handshake form: title, link, preview image, description |
| `cover-image.png` | Preview image for the form (1800 × 1200 px, 3:2) |
| `4-demo/CareerPilot.html` | The finished prototype in one file. Double-click to open it in a browser |

## Steps

**Build**

1. Open the mission in Handshake Learn, then open Figma Make from **Build**.
2. Paste `1-prompts/01-main-flow.txt` and attach screenshots `01` to `07`. Generate.
3. In preview, go from Home to Tracker. Ask Figma Make to fix any button that doesn't open the right screen.
4. Add the other flows one at a time:
   - `02-interview-coach.txt` with screenshots `08`, `09`, `10`
   - `03-resume.txt` with screenshot `11`
   - `04-tracker-actions.txt` (no screenshot needed)
5. Compare against `4-demo/CareerPilot.html` and adjust anything that looks off.

**Publish and submit**

6. Publish the prototype and copy the figma.site link. Paste it into `3-form-answers.md` so you have it saved.
7. Open the link on a phone in a private browser window. Complete the task without signing in: See your matches → first job → Apply with CareerPilot → Submit application → Track application.
8. Open **Share** in Handshake and fill in the form from `3-form-answers.md`: title, link, `cover-image.png` as the preview image, and the description. Edit the description first so it says what you really changed and fixed in Figma Make.
9. Confirm the submission went through.

The brief listed the deadline as **November 30 at 11:59 p.m. PT**. Check the mission page to confirm.
